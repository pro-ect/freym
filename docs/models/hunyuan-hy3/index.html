Tencent Hy3 (Hunyuan 3)

Hy3 is Tencent Hunyuan's flagship 295B-parameter language model. In July 2026 it claimed the top spot on the OpenRouter LLM leaderboard, shipped 1-bit and 4-bit quantized versions, was used in additive combinatorics research, and powers Tencent's Hy3 agent workspace in WorkBuddy, which launched globally in August 2026.

Tencent's Hy3 model advances additive combinatorics research

Tencent's research agent Hyra and the Hy3 model contributed to solving a 50+ year-old open problem in additive combinatorics, improving constructions for the growth rate of sumsets versus difference sets beyond the previous 1.1 threshold.

July 29, 2026feature

Tencent open-sources AngelSpec speculative decoding framework

Tencent has open-sourced AngelSpec, an end-to-end speculative decoding framework for training and deployment. On the Hy3-A21B model, it delivers 1.98–2.40× end-to-end speedup with improved performance across various concurrency levels.

Source: @TencentHunyuan on X →

Hy3 295B model now available in 1-bit and 4-bit versions

Tencent released 1-bit and 4-bit quantized versions of Hy3, a 295B flagship-scale model that can run on a single GPU using llama.cpp and MTP, enabling efficient inference on lower-end hardware.
