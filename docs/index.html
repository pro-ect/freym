How it works

Three nodes, one board.

01

Write or drop

Add a prompt node, or drag an image straight onto the board. Both become inputs you can reuse in every branch.

02

Wire a model

Pick any image or video model from the catalog, connect the wire, and set its own controls — size, references, duration.

03

Chain the result

The output is a node too. Send it into an upscaler, an editor, or a video model, and keep the whole chain on the canvas.
